# קול תורה פלוס כתב יד

גרסה מורחבת של קול תורה: תמלול שיעורי תורה בעברית, עריכת התוצאה וייצוא למסמך DOCX, לצד מסך נפרד לזיהוי טקסט בעברית מתמונות — הכל מקומית במכשיר לאחר התקנה.

## תכונות
- ממשק מלא בעברית ובכיווניות מימין לשמאל.
- הקלטת שיעור וייבוא WAV PCM באמצעות Whisper מקומי.
- מילון החלפות אישי לתיקון צורות כתיב של מילים לאחר תמלול.
- שמירת טיוטות, בחירת גופן וגודל טקסט, ייצוא DOCX תואם Word.
- מסך נפרד לבחירת תמונה של כתב יד או טקסט מצולם, הרצת OCR בעברית ללא רשת והעברת הפלט לעורך הקיים.
- הטקסט שזוהה בתמונה אינו עובר הגהה, תיקון איות, שכתוב או החלפות מילון אוטומטיות. אפשר לערוך ידנית אחרי ההעברה.

## מגבלות הזיהוי
מנוע ה-OCR הכלול הוא Tesseract עם מודל עברי כללי (tessdata_best). הוא מבצע זיהוי מקומי של טקסט בתמונות, אך אינו מודל HTR ייעודי שאומן במיוחד לכתב יד עברי. לכן הוא עשוי להצליח בכתב יד קריא, אך הדיוק אינו מובטח והוא עלול לטעות בכתב מחובר, בקיצורים ובמונחים תורניים. האפליקציה מעבירה לעורך את הפלט המקורי של המנוע, בלי לתקן אותו.

תהליך ההתקנה כולל את נתוני השפה העברית ואת מודל Whisper בתוך ה-APK. לאחר ההתקנה אין צורך ברשת לצורך זיהוי או תמלול. הבנייה דורשת אינטרנט כדי להביא את הקוד והמודלים אל סביבת GitHub Actions.

## בניית APK
ב-GitHub, פתח Actions → Build Kol Torah APK → Run workflow. לאחר הצלחה, פתח את ריצת הבנייה והורד את artifact בשם kol-torah-debug-apk.

## דרישות
Android 6.0 ומעלה (API 23). זו גרסת בדיקה ראשונית; יש לבדוק אותה על מכשיר אמיתי לפני שימוש קבוע. תהליך build מוצלח אינו מחליף בדיקות איכות לזיהוי כתב יד.

## רישיונות
- whisper.cpp: MIT.
- Tesseract4Android: Apache-2.0.
- Tesseract Hebrew traineddata: פרויקט tessdata_best של Tesseract OCR; יש לשמור על הודעות הרישוי והייחוס המתאימות.
