# קול תורה פלוס כתב יד

אפליקציית Android בעברית לתמלול שיעורי תורה, עריכת תוצאות וייצוא DOCX, עם מסלול נפרד לזיהוי כתב יד עברי אופליין.

## תכונות
- ממשק RTL בעברית.
- הקלטה וייבוא שמע. קבצים שהמערכת יודעת לפענח מומרים מקומית ל-WAV PCM 16-bit, 16kHz.
- Whisper מקומי לתמלול בעברית, עם עיבוד במקטעים כדי לצמצם צריכת זיכרון.
- מילון החלפות אישי למונחים שחוזרים בתמלול.
- שמירת טיוטות, בחירת גופן וגודל טקסט, וייצוא למסמך DOCX תואם Word.
- זיהוי כתב יד עברי עם מודל HTR ייעודי Mishkefet-v1 שהומר ל-ONNX מכווץ; זיהוי מקומי לאחר ההתקנה.
- מסך נפרד לטקסט מודפס באמצעות Tesseract OCR.
- תוצאת זיהוי כתב היד נכנסת לעורך כפי שהמודל הפיק אותה — אין תיקון איות, שכתוב או מילון החלפות אוטומטי.

## שיפור זיהוי כתב היד
בגרסאות קודמות השתמש מסך כתב היד ב-Tesseract OCR כללי, שמותאם בעיקר לטקסט מודפס. בגרסה זו הוא משתמש במודל ייעודי לכתב יד עברי מודרני, עם חלוקה לשורות, נרמול תאורה, התאמת גודל שורות, תיקון סיבוב לפי EXIF ואפשרות להריץ כמה קני מידה לשיפור דיוק. הטקסט המודפס נשאר במסלול OCR נפרד.

המודל מבוסס על Mishkefet-v1:
- מודל: https://huggingface.co/itayinbar/Mishkefet-v1
- קוד המקור: https://github.com/itayinbarr/heb-ocr
- משקלי המודל המקוריים: בערך 121MB; בבנייה ממירים אותם ל-ONNX ומכמתים את שכבות המשקולות כדי להתאים להפעלה מקומית.
- המקור מפרסם תוצאות על אוסף בדיקה של כתב יד עברי מודרני, אך אלה אינן הבטחה לדיוק על כל כתב או תמונה.

**מגבלות:** מודל כתב היד מיועד בעיקר לכתב יד עברי מודרני. הוא עלול לטעות בכתב לא ברור, כתב רש״י, קיצורים, ניקוד צפוף או תמונות מטושטשות/עקומות. לא בוצע אימון אישי על כתב היד של המשתמש, ואין תיקון אוטומטי של הטקסט. מומלץ להשוות את התוצאה למקור לפני שימוש בלימוד או בהפצה.

## עבודה אופליין
לאחר ההתקנה, זיהוי כתב היד ותמלול השמע פועלים במכשיר ללא חשבון וללא רשת. תהליך הבנייה של APK דורש אינטרנט כדי להביא את קוד המקור, המודלים וספריות הפיתוח. האפליקציה עשויה להקדיש זמן להעתקת מודלים לאחסון הפנימי בפעם הראשונה בלבד.

## בניית APK
ה-workflow נמצא ב-.github/workflows/android.yml:
1. מתקין Java, Gradle ו-Android SDK/NDK.
2. מוריד ומייצא את מודל כתב היד ל-ONNX מכווץ, ובודק שהגרף תומך ביותר מרוחב תמונה אחד.
3. מוריד את מודל Whisper ואת נתוני השפה העברית.
4. בונה את האפליקציה ומעלה artifact בשם kol-torah-debug-apk.

פתח GitHub Actions ובחר Build Kol Torah APK. יש להמתין לסטטוס Success לפני הורדת התוצר.

## דרישות
- Android 6.0 ומעלה (API 23).
- הקלטות ארוכות עשויות להימשך יותר מאורך ההקלטה עצמה, בהתאם למעבד ולזיכרון.
- זיהוי כתב יד עלול לטעות; בניית APK מוצלחת אינה מחליפה בדיקות על מכשירים אמיתיים ועל תמונות לדוגמה.
